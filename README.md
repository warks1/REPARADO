# Reparado — Beta 1

Beta funcional de navegador, sin instalación ni servidor.

## Abrir
1. Descomprime el ZIP.
2. Abre `index.html` con Chrome, Edge o Safari.
3. La demo guarda los datos en el almacenamiento local del navegador.

## Incluye
- Catálogo de Fontanería, Albañilería/Pladur, Parquet y Reformas integrales.
- Precios mostrados con IVA incluido.
- Solicitud de servicio con datos de contacto, dirección, descripción y fotos.
- Notificaciones internas.
- Asignación interna de operarios.
- Agenda con servicio + operario + dirección.
- Botón directo a Google Maps.
- Chat interno de demostración.
- Facturación y opción de imprimir/guardar en PDF desde el navegador.
- Diseño responsive para PC, tablet y móvil.
- Persistencia local mediante localStorage.

## Próxima fase
Para convertir esta beta en producto real para iOS/Android y varios usuarios habrá que conectar backend, base de datos, autenticación, almacenamiento de fotos, push notifications y publicación mediante Capacitor/Expo.
